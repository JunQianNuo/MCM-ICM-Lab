# 001 · 先复现固定硬度的磨损体积模型

- **决策事项**　确定论文 2501909 首个数值复现里程碑的范围和输入。
- **候选方案**　先验证固定硬度的积分与反演，或同时实现风化硬度、空间磨损分布和爱丁堡案例复算。
- **最终选择**　以毫米制实现固定硬度 WVM，通过等面积深度格计算体积。已知楼梯年龄或日均通过次数时，反推另一项。
- **选择理由**　论文表 4 直接给出毫米制参数，解析式可独立核对。先验证该部分，可以在接入真实深度网格或时变模型时定位误差。
- **风险与局限**　累计磨损只能约束年龄和日均通过量的乘积。时变硬度需要核对累计磨损应如何随时间积分，并取得风化参数。爱丁堡原始深度矩阵和精确校准输入尚待取得。
- **验证结果**　合成栅格的正反两种推算、零深度、非法输入与表 4 的单位回代均通过本地测试。案例输出的回代及复算缺项见[复现记录](../../projects/mcm-2025-a/README.md)。交叉审查待完成。
