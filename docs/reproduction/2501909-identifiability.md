## 1. 观测模型与参数

### 1.1 从 §3 到 §4 的生成链

**[原文]** 单次落脚的线性磨损系数

$$
k_m=\frac{Kd}{H}\quad[\mathrm{mm^3/N}],
\tag{3.3}
$$

其中 $K$ 无量纲，$d$ 为滑移距离（mm），$H$ 为硬度（N/mm²），故 $Gk_m$ 是单次落脚磨损体积（mm³），$G$ 为平均载荷（N）。

**[原文]** 第 $i$ 级踏面的平均磨损深度

$$
\bar d_i=\frac{1}{A_{\mathrm{eff}}}\int_{A_{\mathrm{eff}}} T_iN_{d,i}D_i(x,y)G_ik_{m,i}\,\mathrm dx\,\mathrm dy,
\tag{3.8}
$$

其中 $T_i$ 以天计，$N_{d,i}$ 为次/天，$D_i$ 为归一化落脚空间密度，$A_{\mathrm{eff}}$ 为有效面积。由 (3.8) 可得逐点深度与反演式

$$
d_i(x,y)=T_iN_{d,i}G_ik_{m,i}D_i(x,y),
\tag{3.8'}
$$

$$
T_i=\frac{A_{\mathrm{eff}}\bar d_i}{N_{d,i}G_ik_{m,i}},\qquad
N_{d,i}=\frac{A_{\mathrm{eff}}\bar d_i}{T_iG_ik_{m,i}}.
\tag{3.9–3.10}
$$

**[原文]** 式 (3.17) 设 $D(x,y)=D_X(x)D_Y(y)$，横向用多分量高斯混合、纵向用上行/下行两分量拟合；实测边际为

$$
D_X^{\mathrm{measure}}(x)=\sum_yD^{\mathrm{measure}}(x,y),\qquad
D_Y^{\mathrm{measure}}(y)=\sum_xD^{\mathrm{measure}}(x,y).
\tag{3.17}
$$

$x$ 从左侧递增，$y$ 从踏面前缘向内部递增。等面积网格上，深度和乘单格面积即体积；再除以总体积即无量纲占比。

**[推导]** 在 $D$ 对 $A_{\mathrm{eff}}$ 归一（$\int D\,\mathrm dA=1$）时，(3.8) 化为

$$
\bar d_i=\frac{T_iN_{d,i}G_ik_{m,i}}{A_{\mathrm{eff}}},
\qquad
V_i:=A_{\mathrm{eff}}\bar d_i=T_iN_{d,i}G_ik_{m,i}.
\tag{1}
$$

$V_i$ 是第 $i$ 级的**总磨损体积**，也是深度数据里唯一与绝对年龄/流量直接相关的标量。

## 2. 结构可辨识性

本节只回答“在不加额外证据时，哪些参数组合能从深度数据中唯一确定”。结论先行：**§4 的目标量（绝对年龄、修复、材料来源、使用时间模式）单独靠磨损深度都不可辨识；可辨识的是若干乘积、比值与形状。**

### 2.1 五个精确退化

**引理 1（乘积退化）** 由 (3.9) 与 (3.3)，对任意 $\alpha>0$，

$$
(T_i,N_{d,i},G_i,K_i,H_i,d_i)\ \mapsto\
(\alpha T_i,N_{d,i}/\alpha,G_i,K_i,H_i,d_i)
$$

保持 $d_i(x,y)$ 不变；同理 $G_i\mapsto\alpha G_i$、$K_i\mapsto K_i/\alpha$，或 $H_i\mapsto\alpha H_i$、$d_i\mapsto\alpha d_i$，均不改变观测。**可辨识的只有组合 $T_iN_{d,i}G_iK_id_i/H_i$。**

**引理 2（时间表退化）** 对任意通过率史 $N_i(t)\ge0$，

$$
d_i(x,y)=G_ik_{m,i}D_i(x,y)\int_0^{T_i}N_i(t)\,\mathrm dt
$$

只依赖累计通过次数 $M_1=\int N_i\,\mathrm dt$ 与空间分布 $D_i$。因此“短期高流量”与“长期低流量”只要 $M_1$ 相同、$D$ 相同，深度场**逐点相同**。

**引理 3（路线混合退化）** 设 $D_X$ 是若干落脚模式的混合。把同一模式的质量在“一个人交替使用”与“多个人分别使用”之间重新分配，不改变 $D_X$，因而不改变 $d$。**峰数只识别横向模式数，不识别人数，更不识别是否并行。**

**引理 4（修复—流量—材料三向退化）** 由 (3.9)，表观年龄

$$
T_i^{\mathrm{app}}=\frac{A_{\mathrm{eff}}\bar d_i}{N_{d,i}G_ik_{m,i}}
=\frac{A_{\mathrm{eff}}\bar d_iH_i}{N_{d,i}G_iK_id_i}.
$$

当反演统一使用基准流量和材料参数时，$T_i^{\mathrm{app}}$ 偏小可能来自修复后重新计时、实际流量较低、材料更硬或实际滑移距离较短。这些因素均会在其余条件相同时降低实测磨损。**(4.5) 的 $RSA$ 只能标记“低磨损异常级”，不能判定修复。**

**引理 5（材料来源的尺度退化）** (4.11) 的 $H_t$ 与 $T,N_d,G,K,d,\bar d,A_{\mathrm{eff}}$ 全部相乘/相除；若这些量只有相对误差，$H_t$ 只能给出区间，不能唯一指向某个采石场/树种。

### 2.2 可辨识的不变量

**[推导]** 在 (3.8) 的模型内，下列量是可辨识的（在测量噪声内）：

1. 每级总磨损体积 $V_i=A_{\mathrm{eff}}\bar d_i$；
2. 磨损为正时，可直接计算归一化边际 $D_{X,i},D_{Y,i}$。用两者的乘积还原二维分布需要可分离性；
3. 同级内的形状矩：峰位、峰宽、峰高比、偏度、峰间距；
4. 跨级比值 $V_i/V_j$，在 $N,G,k_m$ 同级相等的假设下等于 $T_i/T_j$；
5. 若 $G,K,d$ 跨级相同且已知相对踩踏量，$H_i/H_j=(T_iN_{d,i})/(T_jN_{d,j})\cdot V_j/V_i$。年龄与流量也都相同时，该式简化为 $V_j/V_i$；
6. 可分离性残差 $\|D-D_XD_Y\|/\|D\|$，用于检验 (3.17) 的乘积假设。

**不可辨识的量**：单独的 $T_i$、$N_{d,i}$、$H_i$、$K_i$、$G_i$、修复时刻、并行人数、绝对使用率。

### 2.3 可辨识性等级

| 结论 | 最低证据等级 | 说明 |
|---|---|---|
| 总磨损体积 | 深度 + $A_{\mathrm{eff}}$ | 直接积分 |
| 形状/峰位/峰宽 | 深度 + 网格 | 与年龄无关 |
| 跨级相对年龄 | 等流量/等材料假设 | 假设不可由数据检验 |
| 绝对年龄 | 独立定年或独立流量 | 否则只给等值类 |
| 修复 | 修复记录/材料/工艺证据 | $RSA$ 仅是筛查 |
| 材料来源 | 硬度 + 岩相/同位素/史料 | 硬度必要不充分 |
| 使用时间模式 | 计数记录或双通道动力学 | $\sigma_x$ 不足 |

## 3. 何种额外证据能支持 §4 的判断

### 3.1 年龄 $T$

| 证据 | 打破的退化 | 需要的精度 | 用法/判定 |
|---|---|---|---|
| 建筑档案、铭文、施工/改建记录 | 引理 1、2 | 年级 | 直接给 $T$ 或先验；再由 (3.9) 反推 $N_d$ |
| 相邻木构件树轮定年 | 引理 1 | 年级 | 给出 $T$ 的独立锚点 |
| 砂浆 $^{14}$C、OSL、热释光 | 引理 1 | 十年级 | 适用时给绝对年代区间 |
| 地衣生长曲线、积尘/烟炱层、涂层剖面 | 引理 2 | 十年级 | 给时间锚点与事件层序 |
| 门票/闸机/摄像头/讲解排班 | 引理 1、2 | 日级 | 直接给 $N_d(t)$，与 $V_i$ 联立求 $T_i$ |
| 重复摄影测量/微侵蚀计/复制踏步 | 引理 1、2 | 年毫米级 | 直接测磨损速率，最有力 |

**判定规则 A1**：没有 A 类（独立年龄或独立流量）证据时，只能报告等值类
$\{(T_i,N_{d,i}):T_iN_{d,i}=V_i/(G_ik_{m,i})\}$，不得报告单点年龄。

### 3.2 修复

| 证据 | 说明 | 判定 |
|---|---|---|
| 修复/翻新档案、施工照片 | 最直接 | 记录时刻即 $T_{\mathrm{repair}}$ |
| 砂浆成分与定年、石材批次 | 新砂浆/异批石材提示重铺 | 与相邻级比对 |
| 工具痕、凿面、边棱锐利度 | 修复面通常保留加工痕 | 与自然磨损面比对 |
| 表面不连续：色差、patina、深度剖面台阶 | 局部重置的形貌标志 | 3D 剖面可见突变 |
| 硬度剖面/回弹 | 新材料或加固层 | 与 (4.11) 联用 |
| 踏步位置（首级/末级/门侧） | 较少落脚可解释低磨损 | 先排除流量差异 |

**判定规则 R1**：仅当 (i) $RSA_i$ 低于阈值 **且** (ii) 至少一项独立修复证据成立时，才判“修复”。否则报告“低磨损异常级，原因未定”，并列出修复/低流量/较硬材料三种解释。

**部分修复的偏差**：若修复后仍残留深度 $d_r$，令年磨损率 $r_i=365.25\,N_{d,i}G_ik_{m,i}/A_{\mathrm{eff}}$（mm/yr），则表观年龄被抬高

$$
T_i^{\mathrm{app}}=T_n-t_{\mathrm{repair}}+\frac{d_r}{r_i},
\qquad
t_{\mathrm{repair}}=T_n-T_i^{\mathrm{app}}+\frac{d_r}{r_i}.
\tag{2}
$$

数值例：$r_i=0.015$ mm/yr，$d_r=0.2$ mm，则表观年龄多 13.3 年。**忽略残余深度会把修复日期估早。**

### 3.3 材料来源

| 证据 | 固定/约束 | 说明 |
|---|---|---|
| 岩相/矿相、粒度、孔隙率、吸水率 | 候选岩种 | 硬度之外的第一独立维度 |
| 稳定同位素（C/O）、微量元素 | 产地指纹 | 可区分硬度相近的采石场 |
| 密度、超声波速、回弹（Schmidt） | $H$ 的独立测量 | 直接约束 (4.11) |
| 史料：采石场/木场、运输与账册 | 来源先验 | 与材质测试互证 |
| 风化模型 (4.13) | $H_0\to H(t)$ | 需温度/湿度史；注意 $T$ 的记号冲突 |

**判定规则 M1**：假设差值近似正态、候选硬度可视作已知量。用以下条件筛查候选材料 $c$

$$
|H_t-H_{c}(t)|>1.96\,\sigma_{H_t},
$$

其中 $\sigma_{H_t}$ 由 (4.11) 的全误差传播给出（见 §4.4）。**硬度差在 1.96σ 内只能写“相容”，不能写“同源”。** 材料来源还需至少一项非硬度证据（岩相/同位素/史料）。

### 3.4 使用时间模式

| 证据 | 能区分 | 不能区分 |
|---|---|---|
| 闸机/摄像头/门票的 $N(t)$ | 短期高流量 vs 长期低流量 | 空间路线 |
| 事件记录（展览、仪式、闭馆） | 流量脉冲时刻 | 单次载荷 |
| 积尘/烟炱/涂层/地衣层序 | 时间锚点与事件顺序 | 绝对人数 |
| 横向 $\sigma_x$、峰数、峰间距 | 路线离散度 | 人数、并行性（引理 3） |
| 脚印几何（长宽、趾向、步态） | 并行 vs 交替、个体差异 | 绝对年龄 |
| 同时占用观测（视频/热成像） | 并行人数下限 | 长期平均 |
| 边缘倒圆/棱角退化（第二通道） | 速率相关历史 | 需通道标定 |
| 深度—倒圆联合动力学 | $T$ 与 $N$ 的分离 | 需 $\beta_r\neq\beta$ |

**判定规则 U1**：若只有深度通道且采用线性磨损（(3.8)），任何“使用时间模式”结论都必须写成累计通过次数 $M_1$ 的等价类；不得把 $\sigma_x$ 直接解释为流量（见 §4.2 反例）。

## 4. 反例与判别实验

以下实验均为**合成算例**，参数取整便于手算；单位、公式与 (3.3)、(3.8)–(3.10) 一致。所有“预期”均可由 (3.8') 逐点计算复现。

**公共参数（合成）**：

$$
A_{\mathrm{eff}}=250\times100=25{,}000\ \mathrm{mm^2},\quad
H=90\ \mathrm{N/mm^2},\quad K=10^{-4},\quad d_s=50\ \mathrm{mm},
$$
$$
k_m=\frac{10^{-4}\times50}{90}=5.5556\times10^{-5}\ \mathrm{mm^3/N},\quad
G=700\ \mathrm{N},\quad
Gk_m=0.038889\ \mathrm{mm^3/pass}.
$$

目标平均深度 $\bar d=1.5$ mm，则

$$
V=A_{\mathrm{eff}}\bar d=37{,}500\ \mathrm{mm^3},\qquad
M_1=\frac{V}{Gk_m}=9.643\times10^5\ \mathrm{pass}.
$$

20 年（7,305 天）对应约 132 次/天，2 年（730.5 天）对应约 1,320 次/天。程序用 $M_1/T$ 保留未四舍五入的流量。

---

### E1 单人交替路线 vs 双人并行

**定义（程序化）**

1. 取横向双峰分布
   $D_X(x)=0.5\,\mathcal N(x;-30,15^2)+0.5\,\mathcal N(x;30,15^2)$（单位 1/mm，裁切到踏面后重新归一），
   纵向 $D_Y(y)=\mathcal N(y;50,40^2)$，同样在踏面范围内归一。$D=D_XD_Y$。
2. 场景 A（双人并行）：两人各以 约 66 次/天走左右轨道，持续 $T=20$ 年。
3. 场景 B（单人交替）：一人以 约 132 次/天交替走左右轨道，持续 $T=20$ 年。
4. 用 (3.8') 生成两组 $d(x,y)$，比较逐点差、峰位、峰高、二阶矩。

**手算**：两场景的累计通过次数均约为 $9.643\times10^5$，$D$ 相同，故

$$
d^{A}(x,y)=d^{B}(x,y)=37{,}500\,D_X(x)D_Y(y)\ \mathrm{mm}.
$$

**预期**：两组深度场逐点相同，且在离散踏面上都积分为 37,500 mm³。横向投影有两个峰，分别靠近两个分量的中心。横向中心点处对应两峰之间的谷。用峰位、峰高或任何只依赖终态深度的统计量都无法区分两种历史。

**判定条件**：

- 定义可区分度 $\Delta=\|d^A-d^B\|_2/\|d^A\|_2$。若 $\Delta<\varepsilon_{\mathrm{num}}$（如 $10^{-6}$），判“不可辨识”。
- 直接的判别观测是踏面上同时占用的人数，例如带时间戳的视频。带时间标签的进出计数和楼梯宽度可以辅助判断。孤立脚印与终态磨损只能约束空间路线。
- 若单人改为以 60% 和 40% 的份额走左右轨道，而双人维持各 50%，横向投影会出现不对称。此时可识别的是落脚份额变化，同时占用仍需要额外证据。

---

### E2 短期高流量 vs 长期低流量

**定义（程序化）**

1. 场景 C（长期低流量）：$T=20$ 年，$N_d=132$ 次/天。
2. 场景 D（短期高流量）：$T=2$ 年，$N_d=1{,}320$ 次/天。
3. 两者 $D$ 相同，$G,k_m$ 相同，用 (3.8') 生成深度场。

**手算**：两场景用同一个累计量 $M_1=37{,}500/(Gk_m)$，分别以 7,305 和 730.5 天计算日均流量。取整后的 $132\times7{,}305$ 与 $1{,}320\times730.5$ 也相等，但两者只是 $M_1$ 的近似，因此生成深度时用未取整的流量。

**预期**：深度场逐点相同；(3.9) 对两场景分别反演会得到 $(T,N_d)=(20\ \mathrm{yr},132)$ 与 $(2\ \mathrm{yr},1{,}320)$，二者都满足数据。**数据本身不能选择其一。**

**判定条件**：

- 只有深度 + 线性模型：报告等值类 $T N_d=\text{const}$，**不得报告年龄点估计**。
- 若有独立计数 $N_d$：$T=M_1/N_d$ 唯一。
- 若有独立定年 $T$：$N_d=M_1/T$ 唯一。
- 若两者都无，但能测第二通道（边缘倒圆）且其流量非线性系数与深度通道不同，可按下面的双通道判据尝试分离。

**双通道判据（可程序化）**：设单次深度磨损 $w(N)=w_0(1+\beta N/N_0)$，单次边缘退化 $w_r(N)=w_{r0}(1+\beta_rN/N_0)$，两通道共享同一 $D$ 形状。定义比值

$$
r:=\frac{d}{c\,z}=\frac{1+\beta x}{1+\beta_r x},\qquad
x:=\frac{M_2}{N_0M_1},\qquad
c:=\frac{w_0}{w_{r0}},
$$

其中 $M_2=\int N^2\,\mathrm dt$，$c$ 是两个通道在参考工况下的基线系数比，须由同一参考面标定；若 $c$ 不可标定，它会与 $x$ 混淆，双通道也失效。反解

$$
x=\frac{1-r}{r\beta_r-\beta}.
\tag{3}
$$

**此式成立的前提**：两通道共享同一 $D(x,y)$ 形状（否则 $r$ 随 $x,y$ 变化，只能逐点或加权平均），且 $\beta_r\neq\beta$。

数值：取 $\beta=0.2$，$\beta_r=0.05$，$N_0=1{,}320$，$c=1$（已标定）。

| 场景 | $N$（次/天） | $x=N/N_0$ | $r$ |
|---|---:|---:|---:|
| C 长期低流量 | 132 | 0.1 | $1.02/1.005=1.0149$ |
| D 短期高流量 | 1,320 | 1.0 | $1.20/1.05=1.1429$ |

两场景 $r$ 相差 12.8%。实际判别取决于两组比值之差的标准误，也应计入通道标定参数的不确定性。

**判据**：仅当 $\beta_r\neq\beta$ 且 $|r^C-r^D|>2\sigma_{\Delta r}$（$\sigma_{\Delta r}$ 为差值的标准误） 时，才允许声称区分了两种时间模式；否则退回等值类。**若 $\beta_r=\beta$，则 $r\equiv1$，双通道也无效**——这是该扩展的硬限制。

### E3 修复、低流量与较硬材料

**定义（手算）**：设 $T_{\mathrm{set}}=100$ 年，某级表观年龄 $T_k^{\mathrm{app}}=2$ 年，故

$$
RSA_k=\frac{T_k^{\mathrm{app}}}{T_{\mathrm{set}}}=0.02.
$$

同一观测可由以下任一条解释（保持 $\bar d_k$ 不变）：

| 解释 | 需要的参数 | 说明 |
|---|---|---|
| 2 年前修复（完全重置） | $t_{\mathrm{repair}}=T_n-2$ | 其余参数沿用基准 |
| 该级流量较低 | $N_k=\bar N/50$ | 假定未修复，真实年龄 100 年 |
| 材料较硬 | $H_k=50\times90=4500$ N/mm² | 数学反例，材料可行性须另核实 |
| 滑移距离较短 | $d_k=50/50=1$ mm | 假定未修复，真实年龄 100 年 |
| 部分修复并保留残余磨损 | $d_r=r_i(2\,\mathrm{yr}-t_{\mathrm{since}})$ | 维修发生在距今 $0<t_{\mathrm{since}}<2$ 年时 |

**预期**：仅凭 $RSA_k=0.02$，表中不同机制可以产生相同磨损体积；数据无法选择。

**判定条件（R1 的可执行版）**：

1. 计算 $RSA_i=T_i^{\mathrm{app}}/T_{\mathrm{set}}$；
2. 若 $RSA_i<0.95$，标记“异常低磨损级”；
3. 检查独立证据：修复档案、砂浆/石材批次、工具痕、3D 剖面台阶、硬度；
4. 仅当至少一项独立证据指向修复时，才输出“修复”；否则输出“原因未定”，并列出前三种解释及各自所需参数；
5. 若怀疑部分修复，按 (2) 用残余深度 $d_r$ 修正 $t_{\mathrm{repair}}$，并报告 $d_r$ 的测量不确定度。

**原文口径提醒 [原文]**：§4.3 先定义 $RSA=\min_iT_i/T_{\mathrm{set}}$，案例却写 $RSA=0.02<0.05$。若 $RSA$ 是比值，阈值应是“接近 1”而非 0.05；0.02 与 0.95 相差 47.5 倍。**复现时必须显式声明所用定义与阈值，并把原文的 0.02 作为报告值保留，不得静默改写。**

### E4 材料来源：硬度反推的误差放大

**定义**：由 (4.11)

$$
H_t=\frac{N_dGTKd}{\bar dA_{\mathrm{eff}}}.
$$

**误差传播**：各因子独立时

$$
\left(\frac{\sigma_{H_t}}{H_t}\right)^2
=\left(\frac{\sigma_{N}}{N}\right)^2+\left(\frac{\sigma_{G}}{G}\right)^2+\left(\frac{\sigma_{T}}{T}\right)^2+\left(\frac{\sigma_{K}}{K}\right)^2+\left(\frac{\sigma_{d}}{d}\right)^2+\left(\frac{\sigma_{\bar d}}{\bar d}\right)^2+\left(\frac{\sigma_{A}}{A}\right)^2.
\tag{4}
$$

数值：

| 各因子相对误差 | $\sigma_{H_t}/H_t$ |
|---|---:|
| 5% | $\sqrt{7\times0.05^2}=13.2\%$ |
| 10% | 26.5% |
| $T,N$ 各 20%、$K$ 30%、其余 5–10% | $42.4\%\text{–}45.8\%$ |

**案例对照 [原文]**：$H_t=90.44$，候选 $93.18$ N/mm²，差 2.74（2.94%）。论文给出的 $\sigma_H=1.8$ 描述的是 §4.3 中不同台阶的 $H_{\mathrm{test}}$ 离散度。应用统计阈值需要另行估计 (4.11) 所得 $H_t$ 与候选硬度之差的标准误。

**判定条件（M1 可执行版）**：

1. 用 (4) 计算 $\sigma_{H_t}$（不要只用硬度试验的重复性）；
2. 若 $|H_t-H_c|\le1.96\sigma_{H_t}$，判“相容”，不得判“同源”；
3. 若 $>1.96\sigma_{H_t}$，判“不相容”；
4. 无论哪种，材料来源结论还需至少一项非硬度证据（岩相/同位素/史料）。

**风化模型 (4.13)**：$H(t)=H_0e^{-(0.0015T+0.02RH)t}$。**记号冲突 [原文/约定]**：此处的 $T$ 很可能是温度（°C），而全文 $T$ 表示年龄（day/year）。复现时改记为 $T_{\mathrm{temp}}$，并确认 $t$ 的单位（年）与 $RH$ 的定义（0–1 还是 %）。若把 $T$ 误当年龄，公式会变成自指。

### E5（附加）$PA$ 与 $RS$ 的尺度依赖

**定义**：按转写，(4.1) 为

$$
PA=D^{\mathrm{available}}(x,y)\sum_x\sum_y\log\frac{d^{\mathrm{ava}}(x,y)}{d(x,y)},
$$

(4.9) 同构。**问题**：权重含 $x,y$ 却在求和号外，量纲与求和范围不闭合；若 $D^{\mathrm{ava}}$ 未归一，$PA$ 随网格点数与总深度线性放大。

**约定**：复现采用

$$
PA=\sum_{x,y}w(x,y)\log\frac{\max(d^{\mathrm{ava}},\epsilon)}{\max(d,\epsilon)},\qquad
w=\frac{D^{\mathrm{available}}}{\sum D^{\mathrm{available}}},
\tag{5}
$$

$\epsilon=10^{-3}$ mm，并同时报告未加权版本作为敏感性检查。

**判定条件**：

1. $PA$ 与 $RS$ 必须报告归一化方式、网格、$\epsilon$；
2. 阈值不能直接沿用 0.05；用重复测量或显式测量噪声模型校准“一致条件下”的差值分布；
3. $PA$ 不对称（$PA(a,b)\neq PA(b,a)$），报告时注明方向；需要对称指标时改用 Jensen–Shannon 散度。

## 7. 结论：能说什么、不能说什么

1. **能说**：每级总磨损体积 $V_i$；横向/纵向形状与峰位、峰宽、峰高比；在等流量等材料假设下的跨级相对年龄；可分离性残差。
2. **不能说（仅凭深度）**：绝对年龄；并行人数；修复与否；材料产地；短期高流量与长期低流量的区别。
3. **证据层级**：
   - A 级（独立、可直接定参数）：档案定年、闸机/视频计数、修复记录、材料岩相/同位素、重复摄影测量；
   - B 级（物理定年）：$^{14}$C/OSL、树轮、地衣、层序；
   - C 级（磨损内部但需模型）：形状矩、跨级比值、双通道动力学；
   - D 级（纯假设）：等流量、可分离、线性磨损、峰数=人数。
   **只由 C/D 级支撑的结论，必须写成等值类或条件结论。**
4. **对 §4 的总体判断**：§4 的指标（$PA$、$RSA$、$RS$、$H_t$、$N_{\mathrm{pass}}$）是有用的**筛查与一致性工具**，但它们不能单独完成“年龄—修复—材料—使用模式”的因果判定；每一条都需要至少一项 A/B 级证据才能升级为结论。这一判断与 §4 原文“需要额外信息”的取向一致，但本文把它形式化为可执行的判定规则与反例。

# 约定：depth[y, x] 单位 mm；x 从左递增，y 从前缘向内递增
# 所有函数只依赖 numpy。输入均为合成数据。
import numpy as np

def local_depth(V, DX, DY):
    """(3.8') d(x,y) = V * DX(x) * DY(y); DX, DY 已归一"""
    return V * np.outer(DY, DX)

def mixture_1d(x, weights, means, sigmas):
    return sum(w * np.exp(-0.5*((x-m)/s)**2) / (s*np.sqrt(2*np.pi))
               for w, m, s in zip(weights, means, sigmas))

# E1/E2：1 mm² 单元的中心点。有限网格分别归一。
x = np.arange(250) + 0.5
y = np.arange(100) + 0.5
left = mixture_1d(x, [1.0], [95], [15])
right = mixture_1d(x, [1.0], [155], [15])
DX_left = left / left.sum()
DX_right = right / right.sum()
DY = mixture_1d(y, [1.0], [50], [40])
DY /= DY.sum()

volume_per_passage = 700 * 1e-4 * 50 / 90
total_passages = 37_500 / volume_per_passage
days_long = 7305
days_short = 730.5
rate_long = total_passages / days_long
rate_short = total_passages / days_short
volume_long = rate_long * days_long * volume_per_passage
volume_short = rate_short * days_short * volume_per_passage

# 并行场景分两条轨道分别累计，交替场景按落脚占比混合。
d_parallel = (
    local_depth(volume_long / 2, DX_left, DY)
    + local_depth(volume_long / 2, DX_right, DY)
)
DX = 0.5 * DX_left + 0.5 * DX_right
d_alternating = local_depth(volume_long, DX, DY)
d_short = local_depth(volume_short, DX, DY)
assert np.isclose(d_parallel.sum(), 37_500)
assert np.allclose(d_parallel, d_alternating)
assert np.allclose(d_alternating, d_short)

    if T_app/T_set >= threshold:
        return "normal"
    return "repair" if independent_repair_evidence else "low-wear, cause unresolved"

# E4: 误差传播
def sigma_H_over_H(rel_errs):
    return float(np.sqrt(np.sum(np.square(rel_errs))))
assert np.isclose(sigma_H_over_H([0.05]*7), 0.1323, atol=1e-3)

# (4.8) 定义域检查
def brinell_analogue_defined(d_bar, A_eff):
    return d_bar**2 >= A_eff
assert not brinell_analogue_defined(1.5, 25_000)   # 原式在踏面尺度无实值
